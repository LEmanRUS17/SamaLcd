# SAMA LCD

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **Русский**

Открытая замена **SAMA WaterCooling** (`Sama.exe`) на C# / .NET 8 для круглого экрана 2,1 дюйма, 480×480 на помпе водяного охлаждения SAMA.

## Начало работы

Нужны Windows, .NET 8 Desktop Runtime и Microsoft Edge WebView2 Runtime. Для некоторых аппаратных датчиков также требуются права администратора и отдельно установленный [драйвер PawnIO](https://pawnio.eu).

1. Полностью закройте оригинальную программу SAMA и отключите её автозапуск. Один COM-порт может открыть только одно приложение одновременно.
2. Соберите и опубликуйте проект по инструкции ниже, затем запустите `publish/SamaLcd.exe`. Приложение запросит права администратора для датчиков.
3. **Изображение** — фон, обрезка, поворот и воспроизведение; **Данные** — темы и редактор раскладки; **Датчики** — показания и ключи; **Программа** — язык, автозапуск, хранилище и диагностика.

Закрытие окна сворачивает приложение в трей. Для полного выхода используйте меню значка в трее. При автозапуске окно настроек не открывается.

Настройки: `%APPDATA%/SamaLcd/settings.json`. Своя раскладка: `%APPDATA%/SamaLcd/custom-layout.json`.

## Язык интерфейса

По умолчанию используется **английский**, в том числе для старых настроек без поля языка. **App → Language** сразу переключает интерфейс между английским, упрощённым китайским, японским и русским. Поле `language` сохраняется как `en`, `zh-Hans`, `ja` или `ru`.

Переведены настройки, редактор, названия датчиков, меню трея, диалоги и сообщения состояния. Свои подписи, имена файлов, ID датчиков и содержимое тем сохраняют исходный текст.

## Фон и применение настроек

- **Галерея** читает изображения, GIF и видео из папки `backgrounds` рядом с приложением. Добавьте файлы и нажмите **Обновить**. Первая плитка восстанавливает фон самой темы.
- **Цвет** предлагает палитру и выбор произвольного цвета.
- **Из источника** поддерживает изображения, анимированные GIF и видео MP4, MKV, WEBM, MOV, AVI и других форматов. Масштабирование: **Заполнить**, **Вписать**, **Растянуть**.

Выбор файла или галереи, цвет, масштаб, обрезка, поворот и способ воспроизведения меняют только локальный черновик предпросмотра. Значок **Не применено** показывает наличие изменений. Экран продолжает использовать последние применённые настройки; при редактировании новое видео не конвертируется и не загружается.

**Применить к экрану** сохраняет и отправляет все настройки изображения вместе, возобновляя воспроизведение, если оно приостановлено. **Отменить изменения** возвращает применённые настройки. Без изменений повторное применение недоступно. Смена языка и яркости не сохраняет черновик изображения; после полного выхода неприменённые правки теряются. Яркость и пауза действуют сразу.

Длинные имена файлов занимают не более двух строк с многоточием; полное имя видно при наведении. **Обрезка / масштаб…** находится в одном ряду с кнопками масштабирования и выровнена по ним.

### Квадратная обрезка и предпросмотр видео

Выберите файл или элемент галереи и откройте **Обрезка / масштаб…**. Перетаскивайте изображение и используйте ползунок или колесо мыши, чтобы убрать чёрные полосы. Область квадратная; круглая маска обозначает видимую часть физического экрана.

Для видео полоса времени позволяет выбрать видимый кадр, даже если начало чёрное. FFmpeg извлекает кадры и для форматов, которые браузер не воспроизводит. Перемотка сохраняет положение обрезки и масштаб. **Использовать обрезку** обновляет черновик; **Отмена** ничего не меняет; **Убрать обрезку** возвращает настройки масштабирования. Завершите кнопкой **Применить к экрану**. Обрезка действует на всё видео и не перезаписывает оригинал.

Изображения и GIF, передаваемые по USB, используют выбранный прямоугольник исходника. Видео и GIF, воспроизводимые самим экраном, получают ту же обрезку через FFmpeg до изменения размера и поворота. Изменение обрезки делает кэш конвертации недействительным.

### FFmpeg и воспроизведение

При запуске `ffmpeg.exe` ищется рядом с приложением, в PATH, кэше инструментов и известных папках SAMA. Если его нет, программа скачивает essentials ZIP и SHA-256 с [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), указанного на [ffmpeg.org](https://ffmpeg.org/download.html), проверяет контрольную сумму и устанавливает исполняемый файл и лицензию. Если папка приложения недоступна для записи, используется `%LOCALAPPDATA%/SamaLcd/tools`. Повторная проверка — **Программа → Проверить FFmpeg**. При ошибке установки статические изображения остаются доступны.

**Видео и GIF играет сам экран** включено по умолчанию. После применения файл преобразуется в 480×480, 24 кадра/с, H.264/yuv420p без звука, загружается и воспроизводится циклически. Показатели темы передаются прозрачным слоем. Кэш: `%LOCALAPPDATA%/SamaLcd/video`; имена на экране: `samalcd_*.mp4`.

При отключении этого режима или ошибке локального воспроизведения с переходом на потоковую передачу кадры идут по USB. На проверенном устройстве измерено около 2,7 МБ/с: примерно 4 кадра/с, если меняется весь кадр. Локальное воспроизведение плавнее.

## Ёмкость и файлы SD-карты

Ёмкость читается до конвертации и повторно проверяется по фактическому размеру готового файла. Сначала кодирование ориентируется на свободное место. Если приемлемого битрейта не получить, используется полная ёмкость, а очистка подтверждается после конвертации. Двухпроходное кодирование предусматривает резерв 512 KiB, запас 10% и целевой битрейт до 2400 кбит/с. Видео не обрезается по длительности ради размера.

Если места достаточно, начинается загрузка. Иначе показываются имена SD-видео, размеры и освобождаемый объём. Удалить можно только точно подтверждённые файлы, размер которых не изменился. Отмена/Esc сохраняет файлы и приостанавливает операцию. Смена исходника или выход отменяет ожидающий запрос. CLI без обработчика подтверждения не может автоматически удалять файлы.

**Программа → Файлы SD-карты** управляет `/mnt/SDCARD/video/`. Открытие вкладки или **Обновить** читает имена, размеры, суммарный объём файлов и ёмкость. **Удалить** в строке подтверждает один файл; **Удалить видео…** — весь показанный список. После удаления воспроизведение приостанавливается, чтобы избежать немедленной повторной загрузки, а список и свободное место обновляются. Изменение списка или переподключение устройства отменяет старое подтверждение. Другие папки SD и внутренняя память не очищаются и не форматируются.

## Датчики и своя раскладка

Недоступные показания отображаются как `--`. Ключи `gpu.*` предпочитают дискретную видеокарту, `ram.*` описывают физическую память. Температура, частота и мощность CPU, а также часть датчиков платы, вентиляторов и помпы требуют PawnIO. При отсутствии показаний CPU появляется подсказка.

**Данные → Своя раскладка** предлагает сетку от 4×4 до 16×16. Перетаскивайте элементы для перемещения, правый нижний угол — для изменения размера. Стрелки двигают выбранный элемент, Delete удаляет. Доступны значения датчиков, полосы, текст, время и дата с настройками цвета, размера, выравнивания и подписи. Правки раскладки действуют сразу.

## Темы

Темы находятся рядом с приложением в `themes/<имя>/theme.json`. В комплекте: `Dashboard`, `Clock`, `Animation`, `Orbit`, `Gauges`, `Minimal`, `Neon`, `Terminal`. Папка темы может содержать изображения и шрифты `.ttf`/`.otf`.

  "background": {

  "widgets": [

    {
      "type": "arc",
      "x": 240,
      "y": 240,

      "value": "cpu.load",
      "startAngle": 135,
      "sweepAngle": 270,
      "color": "#00D1FF",

    {
      "type": "bar",
      "x": 140,

      "width": 200,

      "max": 100
    },
    {
      "type": "image",

Подстановки: `{ключ:формат}`, например `{gpu.temp:0.0}`, `{time:HH:mm:ss}`, `{date:dd.MM}`. Поддерживаются и ID LibreHardwareMonitor; их можно найти во вкладке **Датчики** или через `samalcd-cli sensors`.

## Диагностические логи

**Программа → Диагностика** содержит сохраняемый переключатель **Отладочные логи**, кнопки **Открыть папку логов** и **Экспортировать диагностику**. Основные операции и ошибки записываются всегда. Отладка добавляет действия интерфейса, жесты обрезки, аргументы FFmpeg, текстовые команды/ответы USB, статистику памяти и передачи. По умолчанию выключена и не применяет черновик изображения.

Логи находятся в `%LOCALAPPDATA%/SamaLcd/logs`, содержат время UTC, ID сеансов и операций, ID потоков и стеки исключений. Каждая запись сбрасывается на диск; файлы ротируются при 2 MiB, сохраняется до 10 файлов. ZIP включает логи, снимок среды/устройства/настроек и ограниченную выборку недавних сбоев SAMA LCD из журнала Windows, полученную только для чтения. Медиафайлы, сырые кадры и полные пользовательские раскладки не включаются; автоматической отправки нет.

Для поиска ошибки включите отладку, повторите действия, при необходимости перезапустите приложение и экспортируйте ZIP. Незавершённый сеанс отмечается при следующем запуске. Нативные сбои могут обходить обработчики .NET; журнал Windows даёт дополнительные сведения. Диалоги WebView2 открываются из очереди после завершения обратного вызова согласно [рекомендациям Microsoft](https://learn.microsoft.com/microsoft-edge/webview2/concepts/threading-model#reentrancy). Исключения потока чтения декодера перехватываются и записываются.

## Сборка и разработка

```powershell
dotnet build
dotnet test
.\publish.ps1
```

Публикация помещает приложение в трее в `publish/`, CLI — в `publish/cli/`. Сохраняйте исполняемые файлы вместе с зависимостями и папками ресурсов.

- [SamaLcd.Core](src/SamaLcd.Core): протокол, отрисовка, датчики, цикл вывода и диагностика.
- [SamaLcd](src/SamaLcd): приложение Windows в трее и локальный интерфейс WebView2 с ресурсами daisyUI/Tailwind.
- [SamaLcd.Cli](src/SamaLcd.Cli): консольные утилиты.
- [Тесты](tests/SamaLcd.Tests): сравнение протокола, отрисовка, локализация, подтверждение очистки и диагностика.

Откройте `src/SamaLcd/wwwroot/index.html` обычным браузером для предпросмотра с тестовыми данными. Новые типы виджетов добавляются в `Rendering/Theme.cs`, отрисовка — в `ThemeRenderer`.

Нативный и веб-интерфейс используют общие переводы из `src/SamaLcd.Core/Localization/*.json`. После изменений выполните `node scripts/generate-locales.mjs`, затем `dotnet test`. Сохранённый браузерный пакет позволяет открывать предпросмотр отдельно. При изменении описания поведения синхронизируйте все четыре README.

## Консольные утилиты

Используйте `publish/cli/samalcd-cli.exe`:

| Команда | Назначение |
|---|---|
| `ports`, `info`, `sensors` | Порты, сведения об экране и датчиках |
| `brightness 50`, `color "#FF0000"`, `image pic.png` | Яркость, цвет или изображение |
| `theme <folder> [seconds] [--bg <color-or-file>]` | Запуск темы |
| `render <folder> out.png` | Отрисовка без обращения к устройству |
| `bench [frames]` | Измерение скорости передачи |
| `ls [folder]` | Список файлов и память |
| `upload <file> <remote-path>`, `play <remote-path>` | Загрузка или воспроизведение файла |
| `fit-video <source> <budget-bytes> <output>` | Кодирование с ограничением в байтах |
| `raw <code> [text]` | Экспериментальная команда |

`--port COM3` явно задаёт порт. Перед обращением к устройству закройте другие программы управления экраном.

## Протокол устройства

Проверенный экран использует `VID_1D6B&PID_0121` в рабочем режиме и `VID_1A86&PID_CA21` / `CT21INCH` в загрузочном. Открытие загрузочного порта будит устройство. Проверенный ответ: `chs_5inch.dev1_rom1.88`. Протокол восстановлен из `Sama.exe` и связан с Turing Smart Screen rev C; совместимость зависит от аппаратуры и прошивки.

| Команда | Код | Данные / ответ |
|---|---|---|
| Приветствие | 1 | `C5 D3` → `chs_…rom<version>` |
| Память | 100 | Всего/занято/свободно внутренней памяти и SD, в KiB |
| Список папки | 101 | Путь → `result:dir:…file:a.mp4/b.mp4/` |
| Удаление файла | 102 | Путь файла |
| Размер файла | 110 | Путь → байты; `0`, если файла нет |
| Создание/загрузка | 111 | Путь + размер LE32 → `create_success`, байты, `file_rev_done` |
| Запуск видео | 120 | Путь, флаг 1 → `play_video_success` |
| Остановка видео/медиа | 121 / 150 | Без текстовых данных |
| Яркость | 123 | Один байт; оригинал умножает 0–255 на 0,76 |
| Полный кадр | 200 | W×H×4 байт BGRA |
| Наложение | 202 + 208 | BGRA + маска `[index:24][length:16]…EF 69` |
| Разностный кадр | 204 | Номер BE32, необязательная длина маски BE32, сегменты, `EF 69` |
| Состояние | 207 | `needReSend:X\|renderCnt:N` |

Команда занимает 250 байт: `[code][EF 69][length BE32][flag][0 0][данные с позиции 10]`. Пакеты данных несут по 249 полезных байт. Перед загрузкой остановите воспроизведение. В проверенном устройстве около 2,6 MiB внутренней памяти; ёмкость SD зависит от устройства. Кодирование пикселей и сегментов описано в [FrameCodec.cs](src/SamaLcd.Core/Device/FrameCodec.cs), тесты сравнивают байты с выводом оригинального SAMA.

# SAMA LCD

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [Русский](README.ru.md)

SAMA 水冷ポンプの 2.1 インチ・480×480 円形画面向けに作られた、**SAMA WaterCooling**（`Sama.exe`）のオープンソース代替アプリです。C# / .NET 8 で実装されています。

## はじめに

Windows、.NET 8 Desktop Runtime、Microsoft Edge WebView2 Runtime が必要です。一部のハードウェアセンサーには管理者権限と、別途インストールする [PawnIO ドライバー](https://pawnio.eu) も必要です。

1. 純正 SAMA ソフトを完全に終了し、自動起動を無効にします。同じ COM ポートを同時に開けるのは 1 つのアプリだけです。
2. 下記の手順でビルド・発行してから `publish/SamaLcd.exe` を実行します。センサーのために管理者権限を要求します。
3. **画像**で背景・切り抜き・回転・再生、**データ**でテーマとレイアウト、**センサー**で値とキー、**アプリ**で言語・自動起動・ストレージ・診断を設定します。

ウィンドウを閉じると通知領域に最小化されます。完全に終了するには通知領域のメニューを使います。自動起動時には設定画面を開かず、通知領域で実行されます。

設定：`%APPDATA%/SamaLcd/settings.json`。カスタムレイアウト：`%APPDATA%/SamaLcd/custom-layout.json`。

## 表示言語

既定の言語は**英語**です。言語フィールドのない既存設定でも英語になります。**App → Language** から英語・簡体字中国語・日本語・ロシア語に即座に切り替えられます。`language` の保存値は `en`、`zh-Hans`、`ja`、`ru` です。

設定、編集画面、センサーの別名、通知領域メニュー、ダイアログ、状態メッセージを翻訳しています。独自のラベル、ファイル名、センサー ID、テーマ内容は元の文字列を維持します。

## 背景と設定の適用

- **ギャラリー**はアプリの隣の `backgrounds` フォルダーから画像・GIF・動画を読み込みます。追加後に**更新**します。最初の項目でテーマ本来の背景に戻せます。
- **色**はパレットと任意色の選択に対応します。
- **ファイル**は画像、アニメーション GIF、MP4・MKV・WEBM・MOV・AVI などに対応します。拡大縮小は**埋める**・**収める**・**引き伸ばす**から選べます。

ファイルやギャラリーの選択、色、拡大縮小、切り抜き、回転、画面側再生の変更は、ローカルの下書きプレビューだけを更新します。**未適用**は変更が保留中であることを示します。実機は前回適用した設定を使い続け、編集中に新しい動画を変換・アップロードすることはありません。

**画面に適用**で画像設定をまとめて保存・送信し、一時停止中なら再生を再開します。**変更を破棄**で適用済み設定に戻ります。変更がなければ再適用できません。言語や明るさの変更で画像の下書きは保存されず、アプリを完全終了すると未適用の変更は破棄されます。明るさと一時停止は即座に反映されます。

長いファイル名は最大 2 行で省略表示され、ポインターを重ねると全体を確認できます。**切り抜き／ズーム…**は拡大縮小ボタンと同じ行に揃えて表示されます。

### 正方形の切り抜きと動画プレビュー

ファイルまたはギャラリー項目を選び、**切り抜き／ズーム…**を開きます。ドラッグで位置を調整し、スライダーやマウスホイールで拡大して黒帯を除去します。選択範囲は正方形で、円形マスクが実機に表示される範囲です。

動画ではシークバーで見やすいフレームを選べます。冒頭が黒い場合でも調整でき、ブラウザーで再生できない形式も FFmpeg でフレームを抽出します。シークしても位置とズームは維持されます。**切り抜きを使用**で下書きを更新し、**キャンセル**は変更せず、**切り抜きを解除**で拡大縮小の設定に戻します。最後に**画面に適用**を押します。切り抜きは動画全体に適用され、元ファイルは上書きしません。

静止画と USB で送信する GIF は選択した元画像領域を使用します。動画と画面側で再生する GIF は、サイズ変更・回転の前に FFmpeg で同じ領域を切り抜きます。切り抜きを変更すると変換済み動画のキャッシュは無効になります。

### FFmpeg と再生

起動時にアプリの隣、PATH、ツールキャッシュ、既知の SAMA インストール先から `ffmpeg.exe` を探します。なければ [ffmpeg.org](https://ffmpeg.org/download.html) が案内する [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) の essentials ZIP と SHA-256 をダウンロードし、チェックサム検証後に実行ファイルとライセンスを配置します。アプリのフォルダーに書き込めない場合は `%LOCALAPPDATA%/SamaLcd/tools` を使用します。**アプリ → FFmpeg を確認**で再試行できます。導入に失敗しても静止画は使用できます。

**動画と GIF を画面側で再生**は既定で有効です。適用後に音声なしの 480×480・24 fps・H.264/yuv420p に変換し、実機へ転送してループ再生します。テーマの値は透明なレイヤーとして送信します。キャッシュは `%LOCALAPPDATA%/SamaLcd/video`、転送名は `samalcd_*.mp4` です。

画面側再生を無効にした場合や、再生失敗で USB 送信へ切り替わった場合はフレームごとに送ります。検証した機器では約 2.7 MB/s、全画面が変化する動画では約 4 fps なので、実機側の再生のほうが滑らかです。

## 容量確認と SD ファイル

変換前に容量を読み、変換後に実際のファイルサイズで空き容量を再確認します。まず現在の空き容量に合わせ、実用的なビットレートを確保できない場合は総容量を基準に変換し、完了後に削除の確認を行います。2 パス制御、512 KiB の予約領域、10% の余裕を使い、目標ビットレートの上限は 2400 kbit/s です。容量に合わせて動画を途中で切ることはありません。

空きが足りれば転送し、不足時は SD 動画の名前・サイズ・解放可能な容量を一覧で確認します。承認された一覧内でサイズが変わっていないファイルだけを削除できます。キャンセル／Esc はファイルを保持して処理を一時停止します。元ファイルの変更や終了により確認待ちは無効になります。確認処理のない CLI セッションでは自動削除しません。

**アプリ → SD カードのファイル**は `/mnt/SDCARD/video/` を管理します。ページを開くか**更新**を押すと、名前・サイズ・合計使用量・容量を読み込みます。各行の**削除**は 1 件、**動画を消去…**は表示一覧全体を確認します。削除後は自動再転送を防ぐため再生を一時停止し、一覧と空き容量を更新します。一覧変更や機器の再接続で古い確認は無効になります。他の SD フォルダーや内部ストレージを消去・フォーマットしません。

## センサーとカスタムレイアウト

取得できない値は `--` です。`gpu.*` は独立 GPU を優先し、`ram.*` は物理メモリを示します。CPU の温度・クロック・電力と、一部のマザーボード・ファン・ポンプの値には PawnIO が必要です。CPU の値を取得できないときは案内を表示します。

**データ → カスタムレイアウト**には 4×4～16×16 のグリッドがあります。ドラッグで移動し、右下のハンドルでサイズを変えます。方向キーで選択項目を移動し、Delete で削除できます。センサー値、バー、文字、時刻、日付に対応し、色・サイズ・配置・ラベルを設定できます。レイアウト変更は即座に反映されます。

## テーマ

テーマはアプリの隣の `themes/<名前>/theme.json` にあります。付属テーマは `Dashboard`、`Clock`、`Animation`、`Orbit`、`Gauges`、`Minimal`、`Neon`、`Terminal` です。テーマフォルダーに画像や `.ttf`/`.otf` フォントも配置できます。

```json
{
  "name": "マイテーマ",
  "intervalMs": 1000,
  "background": {
    "color": "#000000",
    "image": "bg.gif",
    "fit": "cover"
  },
  "widgets": [
    {
      "type": "text",
      "x": 240,
      "y": 200,
      "text": "{cpu.temp:0}°",
      "size": 96,
      "bold": true,
      "color": "#FFFFFF"
    },
    {
      "type": "arc",
      "x": 240,
      "y": 240,
      "radius": 218,
      "thickness": 18,
      "value": "cpu.load",
      "startAngle": 135,
      "sweepAngle": 270,
      "color": "#00D1FF",
      "colorEnd": "#FF3B5C"
    },
    {
      "type": "bar",
      "x": 140,
      "y": 300,
      "width": 200,
      "height": 10,
      "value": "gpu.load",
      "max": 100
    },
    {
      "type": "image",
      "x": 0,
      "y": 0,
      "path": "logo.png",
      "width": 100,
      "height": 100
    },
    {
      "type": "circle",
      "x": 240,
      "y": 400,
      "radius": 58,
      "color": "#99000000"
    }
  ]
}
```

文字の置換は `{キー:書式}` で、例は `{gpu.temp:0.0}`、`{time:HH:mm:ss}`、`{date:dd.MM}` です。主なキー：`cpu.temp`、`cpu.load`、`cpu.clock`、`cpu.power`、`gpu.temp`、`gpu.hotspot`、`gpu.load`、`gpu.clock`、`gpu.power`、`gpu.mem.load`、`gpu.fan`、`ram.load`、`ram.used`、`ram.free`、`board.temp`、`pump.rpm`、`fan.rpm`。LibreHardwareMonitor の ID も使えます。**センサー**または `samalcd-cli sensors` で確認してください。

## 診断ログ

**アプリ → 診断ログ**に、保存される**デバッグログ**設定、**ログフォルダーを開く**、**診断ログをエクスポート**があります。基本操作とエラーは常に記録します。デバッグを有効にすると、画面操作、切り抜き操作、FFmpeg 引数、USB テキストコマンドと応答、メモリ・転送統計も記録します。既定では無効で、画像の下書きを適用する操作ではありません。

保存先は `%LOCALAPPDATA%/SamaLcd/logs` です。UTC 時刻、セッション／操作 ID、スレッド ID、例外スタックを含み、記録ごとにフラッシュします。2 MiB ごとに切り替え、最大 10 ファイルを保持します。ZIP にはログ、実行環境・機器・設定のスナップショット、件数を制限した最近の SAMA LCD の Windows クラッシュ記録を読み取り専用で取得して含めます。メディア本体、生フレーム、ユーザーレイアウト全体は含めず、自動送信もしません。

問題調査ではデバッグを有効にして操作を再現し、必要なら再起動して ZIP をエクスポートします。正常終了していないセッションは次回起動時に記録します。ネイティブ障害はマネージ例外処理を通らないことがあり、Windows 記録が追加の手がかりになります。WebView2 のダイアログは[Microsoft のスレッドに関する説明](https://learn.microsoft.com/microsoft-edge/webview2/concepts/threading-model#reentrancy)に従い、コールバック終了後に開きます。デコード読み取りスレッドの例外も捕捉・記録します。

## ビルドと開発

```powershell
dotnet build
dotnet test
.\publish.ps1
```

発行後、通知領域アプリは `publish/`、CLI は `publish/cli/` に配置されます。実行ファイルと依存ファイル、リソースフォルダーを一緒に保持してください。

- [SamaLcd.Core](src/SamaLcd.Core)：機器プロトコル、描画、センサー、表示ループ、診断。
- [SamaLcd](src/SamaLcd)：Windows 通知領域アプリと、同梱の daisyUI/Tailwind を使うローカル WebView2 画面。
- [SamaLcd.Cli](src/SamaLcd.Cli)：コマンドラインツール。
- [テスト](tests/SamaLcd.Tests)：プロトコル比較、描画、多言語、削除の確認、診断。

通常のブラウザーで `src/SamaLcd/wwwroot/index.html` を開くと模擬データでプレビューできます。部品の種類は `Rendering/Theme.cs` に、描画処理は `ThemeRenderer` に追加します。

翻訳は `src/SamaLcd.Core/Localization/*.json` をネイティブ画面と Web 画面で共有します。変更後に `node scripts/generate-locales.mjs`、続いて `dotnet test` を実行します。同梱の言語バンドルで単独プレビューも可能です。動作の説明を変える場合は、4 言語の README を同期してください。

## コマンドラインツール

`publish/cli/samalcd-cli.exe` で使用します。

| コマンド | 用途 |
|---|---|
| `ports`, `info`, `sensors` | ポート・機器情報・センサーを表示 |
| `brightness 50`, `color "#FF0000"`, `image pic.png` | 明るさ・色・画像を設定 |
| `theme <folder> [seconds] [--bg <color-or-file>]` | テーマを実行 |
| `render <folder> out.png` | 機器に接続せず画像を保存 |
| `bench [frames]` | 転送速度を測定 |
| `ls [folder]` | ファイルと容量を表示 |
| `upload <file> <remote-path>`, `play <remote-path>` | 機器へ転送・再生 |
| `fit-video <source> <budget-bytes> <output>` | バイト数の上限に合わせて変換 |
| `raw <code> [text]` | 実験用コマンドを送信 |

`--port COM3` でポートを指定できます。機器へアクセスする前に他の画面制御ソフトを終了してください。

## 機器プロトコル

検証した画面の ID は動作モードが `VID_1D6B&PID_0121`、起動モードが `VID_1A86&PID_CA21` / `CT21INCH` です。起動モードのポートを開くと復帰します。確認した識別文字列は `chs_5inch.dev1_rom1.88` です。`Sama.exe` を解析したプロトコルで、Turing Smart Screen rev C 系列と関連します。互換性はハードウェアとファームウェアによって異なります。

| コマンド | 番号 | データ・応答 |
|---|---|---|
| ハンドシェイク | 1 | `C5 D3` → `chs_…rom<version>` |
| 容量 | 100 | 内部と SD の総容量・使用量・空き容量、単位 KiB |
| 一覧 | 101 | パス → `result:dir:…file:a.mp4/b.mp4/` |
| ファイル削除 | 102 | ファイルパス |
| ファイルサイズ | 110 | パス → バイト数、存在しなければ `0` |
| 作成・転送 | 111 | パス + LE32 サイズ → `create_success`、データ、`file_rev_done` |
| 動画再生 | 120 | パス、フラグ 1 → `play_video_success` |
| 動画・メディア停止 | 121 / 150 | テキストなし |
| 明るさ | 123 | 1 バイト。純正アプリは 0–255 に 0.76 を乗算 |
| 全フレーム | 200 | W×H×4 バイト BGRA |
| 重ね合わせ | 202 + 208 | BGRA + マスク `[index:24][length:16]…EF 69` |
| 差分フレーム | 204 | BE32 連番、任意の BE32 マスク長、セグメント、`EF 69` |
| 状態 | 207 | `needReSend:X\|renderCnt:N` |

コマンドは 250 バイト：`[code][EF 69][length BE32][flag][0 0][オフセット 10 からペイロード]`。データパケットの有効部分は各 249 バイトです。アップロード前に再生を停止します。検証機の内部ストレージは約 2.6 MiB、SD 容量は機器によって異なります。画素・セグメント符号化は [FrameCodec.cs](src/SamaLcd.Core/Device/FrameCodec.cs)、純正出力とのバイト単位比較はテストを参照してください。
